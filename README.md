# Group Čulo whistleblower intake demo

Start the presenter from the checkout or the extracted working-agent ZIP. On Windows run `./n8n/demo.ps1 -Hold`. On macOS or Linux run `./n8n/demo.sh --hold`. Set the private BRANE credentials and install the backend requirements before launch. [Presenter setup and smoke test](n8n/README.md)

Open the printed intake URL, submit a fresh synthetic report and follow the case link to the human review form. The recorded pitch video shows an earlier fixture run.

The [backend guide](backend/README.md) describes governed intake. The [voice guide](voice/README.md) covers the ElevenLabs setup and end-to-end call. The hand-in CSVs are in [submission](submission/) and run records are in [evidence](evidence/).
